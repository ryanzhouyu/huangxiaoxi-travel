景点示例为黄果树的大瀑布、陡坡塘、天星桥，甲秀楼的浮玉桥、甲秀楼、翠微园，以及小七孔的小七孔古桥、翠谷瀑布、卧龙潭。样稿中的待到访只用于展示，选中时仅描出印章边缘。正式状态对应有效到访记录，每个点可自由查看，原画和节点之间的连线为视觉示意。[黄果树景区介绍](https://www.tongren.gov.cn/2023/0502/299187.shtml) · [甲秀楼景区介绍](https://szb.eyesnews.cn/pc/cont/202402/23/content_118067.html) · [小七孔景点资料](https://sthj.guizhou.gov.cn/zwgk/zdlyxx/fsjg/fslxmslgs/202302/P020230222418037519120.pdf)

## 游戏参考

- 《星之卡比 机械星球》手册分开世界地图和区域地图，先选区域，再在区域内选关卡。本稿对应贵州概览、景区章节、景点三级关系。[任天堂游戏手册，第 12 节](https://www.nintendo.com/eu/media/downloads/games_8/emanuals/nintendo_3ds_2/kirbyplanetrobobot/ElectronicManual_Nintendo3DS_KirbyPlanetRobobot_EN.pdf)
- 《超级马力欧兄弟 惊奇》在部分世界地图开放区域允许自由移动，地图先提供探索空间，再给出关卡入口。本稿让景区长在可辨识的地形上，并延续项目的自由到访规则。[任天堂官方玩法介绍](https://www.nintendo.com/au/news-and-articles/experience-the-unexpected-in-super-mario-bros-wonder-gameplay-presentation/)

## 原画和验收

[贵州地图原画](./assets/guizhou-atlas.webp)为 ImageGen 内置工具生成的概念素材，压缩为 WebP。项目的[既有山水原画](../../../design/hifi/assets/map.png)作为画风参考。作图指令为纵向满幅、45° 俯视的原创贵州山水地图，以暖纸、喀斯特山石、翠水与雾气续接现有画风。甲秀楼居画面中右，黄果树瀑布在左，小七孔七拱桥在右下，用依地形展开的浅色山路衔接三处。上方留出标题与筛选空间，原画内无字、图标或界面元素。

Windows Chrome 独立上下文检查 360×640、390×844、430×932、1280×720、1440×1000。检查默认三点同屏、按钮边界、画面覆盖及底栏衔接。三处章节均点击进入，验证景点选中与返回地图。另验证两个筛选叠加、重置及从本地文件打开。按本轮范围提供独立视觉样稿，地理比例、点位数据和实际到访业务需要后续接入验证。
