## 画面与筛选

- 沿用现版「发现贵州」页头、山水原画和共用底栏。山水场景从页头延续到导航背后，三处景区各占一张同宽、同级的明信片。
- 每张卡先显示可辨识的地标，再在纸边左侧用楷体写景区名，右侧用小一号字写归属和类别。三张图逐张裁切，保留黄果树瀑布水脉、甲秀楼楼顶与主体、小七孔桥孔与水面倒影。
- 用户已确认按地市州筛选。左边从全部市州中选安顺市、贵阳市或黔南州，右边固定展示全部、自然风光、人文。两项可叠加，苔绿色表示已选，空态可一键恢复全部。
- 展示分组暂定黄果树和小七孔为自然风光，甲秀楼为人文。样稿只模拟这三条数据筛选后的视图，整页视觉与景区分类待评审。

## 实屏验收

Windows Chrome 独立浏览器上下文验证 360×640、390×844、430×932、1280×720 和 1440×1000。检查文本、地标裁切、背景与底栏衔接，以及最短屏滚到底后的可见范围。390×844 首屏完整展示三张卡，360×640 的列表独立滚动，底栏固定可见。用实际点击验证自然风光、人文、黔南州、空态恢复和 Esc 关闭筛选。直接打开样稿 HTML 文件也能查看图片及试用筛选。真机表现待后续接入时验证。
