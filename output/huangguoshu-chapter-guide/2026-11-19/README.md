## 已确认的交互

- **景区地图**。保留青绿山水、顶部景区信息和三项底部导航。已打卡用实心足迹章，未打卡用空心铜环，商户用手作铺造型。点位旁显示适用的首访票券及已解锁卡池的收集章。点亮表现当前焦点，打卡记录和卡池解锁各自有状态。
- **景点详情**。轻点地标或地名一次即可打开居中弹层。查看当前点位关联的各个卡池、解锁条件或共享点位，逐项看到套装、表情、动作和背景的收集状态。首访或首次到店奖励单独显示。短屏在弹层内滚动，收起后焦点回到原点位。
- **景区概览**。底部持续显示全景区的集齐进度、两套主推服饰横图及各类奖励数量。全套部件齐全才计为集齐。「全部奖励」可查看各卡池及其归属。共享奖励用同一资产 ID 去重。

正式点位和奖品分配需在接入时核对。2/6 套、手作铺、各池状态、首访次数及其余四套的名称与套装章均为评审样例。真实到访、发奖、抽取及失败恢复以[一期产品规则](../../../docs/一期产品规则与业务流程.md)为准。

## 归档复验

在 Windows Chrome 独立上下文重放 360×640、390×844、430×932、1280×720 和 1440×1000，逐一点开陡坡塘、大瀑布、天星桥和手作铺，核对弹层居中位置、奖品和收集状态、关闭回焦及全景区概览。另验证 30px 模拟底部安全区、360×400 的触屏滚动、共享卡池、多池点位及奖励读取失败重试。手机触屏和安全区均为浏览器模拟。

归档前后同状态截取 9 张画面，8 张逐像素一致。剩余的 360×400 触屏滚动实屏存在小幅像素差，人工对照弹层位置、首访奖励和固定标题，布局一致。运行用的四份图片与确认稿的 SHA-256 均一致。本地文件打开、文档链接检查、前端语法检查和 14 项本地域规则测试通过。
