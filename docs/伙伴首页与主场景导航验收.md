# 伙伴首页与主场景导航

2026-11-18。范围为游客评审原型的伙伴首页及伙伴、游玩、回忆三个主入口。基线 `3a37ef1`。依据[黔山同行确认稿](高保真设计说明.md)、[首页历次评审](伙伴首页UI修订与验收.md)和[本轮衣橱与手账确认结果](衣橱与回忆接入计划.md)。

| 顺序 | 改动与目标 | 验收 |
| --- | --- | --- |
| 1. 检查现版 | 同账号、同搭配、同尺寸截图，定位两套导航和背景接缝。 | 比较首页人物与入口、游玩地图下沿、手账书尾和制作按钮。 |
| 2. 收口三处导航 | 沿用手账的头像、地图和册子，统一位置、字、选中态与触区。首页和游玩让原画延伸到导航；手账侧沿书尾接木桌面。 | 三页顺序、尺寸、状态一致。手机安全区有足够空间，页面切换后只有一个当前入口。 |
| 3. 打磨伙伴首页 | 保留夜景和人物，重新组织身份、景区、次数、道具和对话。重点看人物比例、道具图文辨识、对话承托及底部过渡。 | 首次和到访后都能看清全身，衣橱、图鉴、打卡、动作、见面礼、景区、身份和次数均可达。点人物或对白能回应。 |
| 4. 专项及主线回归 | 先跑动作、返回和手账阅读，再逐张看画面。 | 核对 360×640、390×844、430×932、1280×720、1440×1000 和模拟底部安全区。登录、初次选择、独立衣橱及制作页无主场景导航。 |

本轮先完成首页和三处共用导航。游玩地图的点位与到访详情作为后续工作。

## 实施与验收结果

| 项目 | 处理与已观察结果 |
| --- | --- |
| 导航共用 | 三页使用同一个导航模板。顺序始终是伙伴、游玩、回忆。头像、地图、册子、字体、图文位置、44px 触区和暖纸选中标记一致。页面切换和浏览器返回各只有一个当前入口。 |
| 夜景与游玩地图 | 同一张原画贯穿内容区和导航底部，导航背后随着原画逐步收暗。在相同尺寸的前后稿复核底部接缝、文字和触区。 |
| 木纹交界 | 第一轮去掉托架边线后仍能看见木纹明暗跳变。用书尾素材的木纹边缘延续到托架，再向下收暗。核对书尾、制作按钮和三项导航。 |
| 首页画面 | 顶部归拢头像、身份与景区，票券独立显示。图鉴改用独立册子，打卡改用地点标记，初见礼改为横排。道具退到人物两侧，对白和下方导航保留各自的阅读层级。 |
| 首页交互 | 独立未到访身份实际点击人物、对白、衣橱、图鉴、打卡、动作、见面礼、景区、身份和次数。验证返回、动作弹层及键盘切换导航。 |
| 技术回归 | Chrome 157 跑过 5 个视口、额外 1 组模拟 30px 安全区及首次到访前状态，专项采集 19 张。衣橱与手账专项 42 张，端到端回归 25 项、91 张，单页及长图实际下载。领域 14 项、语法和文档检查通过。 |
