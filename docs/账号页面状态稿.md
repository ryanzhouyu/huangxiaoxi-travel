# 账号页面与关键状态稿

2026-11-08，R01-02。沿用黔山同行视觉及三个主场景；本稿明确页面布局、有效操作与状态变体，供后续样式实现，不代表已修改游客界面。真实短信暂缓，迁移入口按[独立方案](演示进度迁移方案.md)待收口；不在游客页放不能工作的发码按钮。

## 共用布局与交互约束

账号前置页共用现有暖色场景、伙伴、纸质操作面板与按钮体系。上部以伙伴相遇／回应为主体，下部呈现本页唯一主要操作；不加统计卡和步骤菜单。登录、验证码和初始化均无底部“伙伴／游玩／回忆”导航。说明文字不挤压手机号／验证码输入和主操作，软键盘出现后允许滚动，不能遮挡错误提示或确认按钮。

页面标题、输入标签、错误说明都使用真实文本；图像不承载不可读的表单文字。错误与字段邻近，焦点可到达，不能仅靠颜色表达。请求期间保留输入、显示具体反馈；焦点与滚动位置不因倒计时每秒重置。动态成功只在服务确认后出现。

## A01 登录：输入与发送

进入条件：没有有效服务端会话；合法原目标已保存。主操作为“获取验证码”，非登录成功；协议说明展示当前真实版本，不预选同意、不让未就绪的空链接进入界面。当前开发阶段如果采用测试身份，显示独立开发入口及其明确标识，不能仿冒本页短信成功。

| 状态 | 画面／可操作项 | 下一步与恢复 |
| --- | --- | --- |
| 初态 | 单个手机号字段、发送按钮、必要协议；输入国家地区范围以接入确定值显示 | 输入本身不写业务进度；号码不放返回 URL |
| 格式错误 | 字段下说明可更正之处，保留号码；主操作不发送 | 修正后可重试；格式正确也不代表真实身份 |
| 发送中 | 输入保留，按钮显示“正在发送”；阻止重复发送 | 回调必须核对本认证流程 ID；离开后的旧结果不跳页 |
| 明确失败 | 错误原因或可理解的暂不可用反馈，重试／更正 | 不展示验证码已发送，不假倒计时 |
| 状态未知 | “正在确认发送结果”，查询原挑战 | 不循环新发短信；保留安全目标，超时可稍后查询 |
| 请求被接受 | 转验证码页，显示脱敏号码和实际冷却 | 文案区分“请求已提交”与“已送达”；只用平台真实可知状态 |

## A02 验证码：验证与更正

进入条件：有效挑战关联，不能只凭 URL 输入手机号打开。顶部“更正号码”返回 A01 并使旧挑战不能误关联新输入。验证码采用连续文本输入，支持粘贴和平台可用的自动填充；显示为分格时底层仍保留可访问输入，不逐格强制焦点跳跃。

| 状态 | 画面／可操作项 | 下一步与恢复 |
| --- | --- | --- |
| 待输入 | 脱敏号码、验证码、重发状态；主操作“验证并进入” | 不在浏览器持久化验证码 |
| 冷却／可重发 | 服务端时间决定剩余秒数或重发按钮 | 更正号码保留原游玩目标；重发只更新挑战，不写账号库存 |
| 错误／过期／限流 | 与输入相邻的不同提示；可更正／按服务冷却重试 | 不泄露手机号是否拥有某套服装或旧作品 |
| 验证中 | 禁止重复消费、保留输入 | 认证超时先核对会话／挑战状态，不再次自动初始化 |
| 已认证、进度未取到 | 独立“正在恢复进度”或读取失败面板 | 读取失败不能当作新账号；提供重试，不显示空白新角色 |
| 已认证、成功读取 | 已初始化回合法目标；未初始化进入 A03 | 登录本身不领取、不记录到访、不抽取 |

从短信应用切回、刷新或微信返回时，使用原挑战关联查询；旧挑战过期则保留目标并重新获取。不要求外跳浏览器才能继续主线。

## A03 首次初始化及迁移分支

进入条件：服务确认该账号尚未初始化。场景与角色预览在上，三套免费初始搭配在下；“确认这位同行伙伴”单一主按钮，全部初始装扮免费。仅切换预览不保存；提交携带原 requestId，未知结果先查回，成功后恢复原点位确认页或伙伴。

迁移方案若获批准：尚未初始化的受邀账号可通过独立“带回已有演示手账”入口进入 M01；入口只在服务确认资格时出现，不作为所有游客必须经过的步骤。已有云进度的账号不能以此覆盖；初始化与迁移竞争由服务端锁与状态检查处理。源手账已初始化则完成迁移后跳过再次选择初始装扮。

离开／换账号前保护已选预览但不跨账号复用；新账号不继承前一账号的初始提交请求。初始化失败保留选择，返回登录不伪装保存成功。

## A04 会话失效与恢复

失效发生在只读页：保留合法路由，认证恢复后重新读取。发生在衣橱／制作：按原账号保护草稿，保存业务请求引用但不存敏感验证码。发生在抽取／支付模拟／迁移提交后响应丢失：先显示结果未知，认证为同账号后查询原请求；另一账号进入时隔离，不能直接重试原写入。

提示层只有“重新验证”与当前可行的离开／返回；不得让关闭层后继续使用已失效身份写入。恢复同账号不跳默认首页丢掉原来点位、订单或制作来源；请求结果已完成时展示该结果，不重新抽取或重复迁移。

## A05 账号资料、退出和恢复支持

账号页属于详情，使用返回按钮，不机械复用主菜单。展示真实脱敏身份和可解释的同步状态；“已同步”基于服务确认版本，不能来自定时器。资料加载失败保留入口和重试，不显示另一账号缓存。

| 状态／入口 | 必须显示与执行 | 不应出现 |
| --- | --- | --- |
| 普通账号页 | 当前身份、返回、退出、已准备好的支持路径 | A/B 切换、清空演示、任意改余额 |
| 有未保存草稿退出 | 说明本机草稿影响，提供取消；草稿保留／丢弃按 D07 最终政策 | 静默丢稿、自动删云数据 |
| 有未知写入退出 | 提示先查结果或确认离开；保留原账号查询关联 | 宣称该交易已取消／已回滚 |
| 撤销中／失败 | 显示撤销进度；失败明确未确认退出，阻止继续写入并重试 | 仅隐藏头像即宣称服务会话已撤销 |
| 恢复账号 | 同渠道重新验证；号码不可用时只有已经落实的支持途径 | 凭昵称／演示截图直接恢复或合并 |
| 绑定／删除 | 第二渠道和删除支持政策实现后才出现，说明真实处理范围 | 尚不存在的微信绑定按钮、清空存档冒充注销 |

## M01—M04 迁移候选页面状态

此组是 D07 方案预览，需范围收口后实现；不改变普通游客主线。

| 页面 | 信息顺序与操作 | 成功／失败／返回 |
| --- | --- | --- |
| M01 选择来源 | 说明只导入演示测试进度、选本机文件、明确选 A/B；此时不上云 | 显示选中手账摘要；取消回 A03；空文件／结构损坏保留原件并列问题 |
| M02 确认范围 | 目标身份、装扮／次数／经历／作品数量、源时间、只读订单、不迁移项、来源差异 | “申请迁移”上传所选来源；另一手账不上传；目标已有数据则禁止覆盖并说明 |
| M03 审核／准备／提交 | 当前状态、可查询进度、原来源摘要；未开始提交时可取消 | 准备失败按原批次重试；提交未知查结果；换账号立即隔离 |
| M04 结果核对 | 实际迁入数量与目标、作品读取结果、测试来源提示 | 全部读回完成才显示“迁移完成”；进入伙伴／原目标；不能同时诱导再领首次奖励 |

没有作品时不显示假上传步骤。审批拒绝、文件损坏、资源 ID 未识别、目标冲突分别指明处理方向；不把“忽略问题继续”设为默认操作。

## 实现后的验收清单

- AU01—AU08：真实身份、前置、恢复、撤销与账号隔离；短信暂缓时明确未执行，不以测试身份通过。
- SY03、UX01：新用户扫码恢复原点位、初始化不显示游玩导航、草稿不串号、旧请求不重放；角色与表单层级沿用确认视觉。
- 手机和桌面实际点击、滚到底部；手机补软键盘、切短信应用、微信返回、刷新和多标签失效；360×640 不遮按钮，长错误文案不溢出。
- M01—M04：按迁移专项的授权、并发、文件失败与回退场景验收；未获批准的方案不成为运行功能。

本轮只完成页面／状态设计及导航契约测试，没有实施样式、短信认证或迁移页面；不能把这些状态稿当作新的浏览器验收截图。
