# 业务规则与范围

2026-11-12。正式首发免费，购买暂不开放。历史逐条确认保留于[源提交产品文档](https://github.com/ryanzhouyu/huangxiaoxi-travel/blob/e5fb44a52c8b63fb6d0b3566e2f4094e08d134d7/docs/一期产品规则与业务流程.md)。以下为有效规则摘要；本地代码不是生产权威。

## 主线

初次进入 → 默认搭配 → 在线浏览景区／领取见面礼 → 实地核验与记录 → 获得次数／解锁池 → 抽取 → 试穿／保存 → 用经历制作、保存和分享回忆。实地游玩可循环，无需先选路线或手动开始／结束。

| 环节 | 已确认规则 |
| --- | --- |
| 数字伙伴 | 黄晓西固定脸部身份，代替游客承载回忆；不要求上传游客本人形象。发型、服装、表情、姿势和背景可换。 |
| 初始化 | 三套初始装扮均免费，选择只决定默认搭配；重复初始化不能重置已保存搭配。 |
| 见面礼 | 在线领取景区套装，获得与穿戴分开；不产生到访、次数或解锁。 |
| 经历 | 核验成功才记录经历；按景区跨日积累，随时制作回忆。 |
| 地点 | 入口／景点每账号每地点首次有效到访发次；重复到访可记录但不重复发奖。 |
| 商家／活动 | 到店和每项消费／体验资格独立，均为每账号一次；体验须可信店员／服务核验。 |
| 次数 | 景区内通用，不跨景区。缺次展示剩余免费机会，没有机会如实提示，不凭空补次。 |
| 卡池 | 地点和池可灵活关联、多点共享；首次有效到访任一关联点解锁，之后可远程抽取。 |
| 抽取 | 统一资产 ID，所有池排除已拥有项；当前剩余项等概率。收齐／失败不扣次，同请求不重复扣／发。 |
| 换装 | 草稿与保存搭配分开，保存更新伙伴与新出图，取消恢复；离开未保存编辑须提示，返回完整来源。 |
| 回忆 | 至少一条有效到访即可制作，不要求收齐。选择跨日经历不删除原记录。 |
| 图片 | 固定模板合成伙伴、背景、时间、路线；用当前保存搭配。旧作品固定图片与来源快照，不随换装或素材更新改变。 |
| 不纳入首发 | 购买、支付、宠物、视频生成、实体纪念品下单。备用录像不等于视频能力。 |

## 测试配置与当前替身

- A/B 为本地身份，进度在 localStorage，草稿在 sessionStorage；无服务器或跨设备同步。
- 一个测试景区、四地点、一个活动、两池、六套衣服。入口／望山台／花溪各 2 次，到店 1 次、活动 2 次，共 9 次免费机会。这些数值不等于真实景区投放方案。
- 两池各 7 件，2 个共有项，共 12 个不同奖品；9 次免费奖励不足以单账号收齐全部 12 件。本轮不为展示收齐而改奖励，正式投放目标由运营另定。
- 测试码只核对内容，不证明到场；定位和店员结果为标识清楚的模拟。60 秒同方式重复记录限制是本地默认值，非新增产品规则。
- 静态姿势／笑眼和点击反馈不满足生产连续动画要求，当前渲染路线未冻结为生产引擎。
- orders 字段只兼容旧数据读取；新订单、支付方法、套餐价格和购买 UI 已移除。
