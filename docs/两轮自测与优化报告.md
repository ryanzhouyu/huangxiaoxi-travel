## 第二轮 操作逻辑优化

| 编号 | 观察 | 已落实的处理 |
| --- | --- | --- |
| O01 | 次数不足只提示去打卡，游客还要自己找可领奖地点，也可能再次前往已领过的点位 | 直接列出本账号尚未领取首次奖励的地点和未完成的活动，显示对应次数并直达；已领地点不再列为获次机会。领完时说明免费奖励已领完，保留继续游玩和模拟购买 |
| O02 | 获得装扮后继续抽取，需要先关结果层再点一次 | 在结果层提供继续单抽；余额不足则转到获次来源，收齐后去看其他装扮。仍可立即试穿或先收好，不强制换装 |
| O03 | 标题修改后示意画面不立即变化；保存作品后再次制作仍沿用已完成作品的经历与模板 | 标题即时更新到示意画面；作品保存成功后清理已完成的制作选项，新制作默认选择现有全部经历。未完成草稿及制作中换装的上下文继续保留，再次制作旧作品仍能带入原作品选项 |
| O04 | 从订单明细继续模拟支付后，只能留在明细页，需自行重新找卡池 | 新订单记录来源卡池，到账后可直接回原池；购买次数仍属于整个景区。旧订单没有来源时保留通用返回入口 |

## 后续建议

1. **地图点位摘要可以进一步减少跳页。** 目前点地图进入详情，再扫码或看卡池。下一轮可探索在地图上先展开地点摘要，同时给出看详情与去打卡；需要配合地图布局评审，避免面板遮挡其他标记。本轮保留已认可的地图结构。
2. **明确全部卡池收齐后的剩余次数展示与用途。** 当前收齐卡池不会继续扣次，也不在该池继续推购买；原有余额保留。后续新增卡池能否继续使用、是否另设规则，需要产品决定。本轮没有擅自添加有效期、清零、退款或兑换规则。

这两项不阻塞当前原型主线，适合下一轮讨论。正式素材替换、跨设备同步及服务端核验属于后续接入工作，本次没有扩大到这些范围。
