# 伙伴首页竞品调研与重设计

本页为 `4adf46c` 的历史候选记录。用户确认横排托架构图退出首页，原构图用于继续打磨。当前以[首页构图恢复与细节修订](伙伴首页与主场景导航验收.md)为准。

基线为 `d196dad` 的伙伴首页。上一版完成了三主场景导航共用，首页仍是中心人物、左侧四张道具牌、右侧初见礼、底部整幅对白。用户反馈构图变化有限，要求先看同类产品首页，再用已确认的衣橱和手账经验重做。

## 确认稿的复用及落点

| 区域 | 新结构 | 验收 |
| --- | --- | --- |
| 场景和人物 | 用[衣橱](衣橱验证设计.md)的「完整人物先看、操作离开舞台」做法。夜景保留同一母版，重新控制裁切、冷暖及人物周围明暗，脚下有接触阴影。 | 对比同一搭配，人物区域内没有道具按钮。竖屏、矮屏和桌面能见鞋底及裙摆，表情和招手都在画面内。 |
| 抬头信息 | 左边用项目楷体的人名和单行景区入口，右边用小票券和仅未领取时出现的见面礼。 | 文字和图标对应身份、景区、次数、初见礼，各自可点，礼包状态前后舞台位置不跳。 |
| 对白与道具 | 一行对白在脚下的暗色场景内。衣橱、图鉴、打卡和动作收进整块暖纸道具区，领取留在见面礼原路径。用衣橱的统一触区和手账的单一材质表现。 | 占位、字重、图标大小和分隔线统一，没有横竖混排；衣橱、打卡、动作和图鉴可直接点击。人物与对白都能回应，键盘焦点留在发起位置。 |
| 底边 | 借[手账](衣橱与回忆接入计划.md)原木纹的承托方式，从夜景地面渐入木托架。托架做共用导航与道具区的底，三主场景的导航标记位置一致。 | 360×640、390×844、430×932、1280×720、1440×1000 和模拟 30px 安全区逐屏核对。检查画面交界、字号、人物裁切、地点和底部点击，不用单张宽屏图代替。 |

先按同数据定义 390×844 的前后对照，再验证初见、到访后、见面礼已领、不同搭配以及招手回应。验收分首页视觉和交互主线两轮。主要变化是从两侧道具包围人物改为「连续舞台＋对白＋横向道具托架」。游玩详情继续按现行路线推进。

## 实屏验收

| 检查 | 结果 |
| --- | --- |
| 同搭配对照 | 上一版 `d196dad` 与新版都用山野来信、两次余额和同一条山门记录。在 390×844 对照道具位置、焦点、文字、各层材质和地面。第一轮矮屏中鞋底落在栏杆高度，修订背景裁切后脚落在石板区。 |
| 小屏和替换搭配 | 360×640 加 30px 底部安全区仍能看到人物全身、对白、四个道具及三个导航入口。穿戴黔山初见、切到山色留白并招手，头饰、裙摆和脚底完整。山色背景用原石板作为前景，避免人物落在远处山谷。见面礼已领时入口隐藏，舞台和道具位置保持。 |
| 功能与焦点 | 点击人物与对白能切换台词，键盘焦点留在原控件。已拥有招手时更换展示姿势，不写入保存搭配。八个入口、浏览器返回和三处导航的视觉尺寸已复验。 |
| 回归 | Chrome 157，5 档视口及额外 30px 底部安全区，专项 21 张实屏。25 项端到端回归通过，实际下载单页和长图 PNG；14 项领域测试通过。真机微信和手机浏览器待验。 |
