# 衣橱与回忆接入计划

2026-11-18，接入目标为游客评审原型 `design/review/index.html`。衣橱以 `9391a63` 的确认样板为准。回忆以 11 月 18 日评审过的旅行手账为准，覆盖足迹、作品册及相应状态。照相馆制作、预览及作品详情沿用游客原型的实际流程，并复核与两份设计的衔接。业务约束以[一期产品规则](一期产品规则与业务流程.md)及[动作与服务交接](前端动作与服务交接.md)为准。

| 顺序 | 还原内容 | 放行条件 |
| --- | --- | --- |
| 1. 衣橱接入 | 全幅工坊、居中全身、七类、底部快选、三列服饰和两列背景、单品大图、保存勾标和试穿描边。复用游客账号库存、试穿草稿、保存版本和来源地址。 | 从伙伴、见面礼、卡池与照相馆实际进入。图鉴、大图、网格返回保持类别、滚动和草稿。验显式保存、放弃、拒绝、冲突及刷新恢复。 |
| 2. 手账接入 | 连续纸页、页眉、装订和书尾、共用深木托架。按日期分组。景点用对应景观，活动与到店用印签。同地点回访复用图片。还原无足迹、无作品、筛选无结果和两类作品缩略。 | 比对同数据的首屏、末尾、空态、详情和图文对应。日期先选再确认。单条、全部或所选范围进入实际制作。作品缩略和打开的成品使用同一原图。 |
| 3. 照相馆闭环 | 实际制作草稿、保存搭配、生成预览、收藏、下载和作品来源。 | 从制作换装，返回核对标题、模板、勾选经历和完整来源参数。用新保存搭配生成并打开 PNG，对照保存的成品和经历快照。换装后旧作品字节一致。 |
| 4. 验收与交接 | 功能一轮，视觉另查。 | 对照两份样板核对 360×640、390×844、430×932、1280×720、1440×1000，以及模拟底部安全区。归档实屏、可复验记录、导出文件和未验证边界。 |

预览和界面状态留在前端，保存及进度沿用游客评审服务。用独立测试账号执行主线。批量评审配色只用于观察衣橱容量。
