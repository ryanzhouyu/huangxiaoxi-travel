# 黔山同行游客演示 · 视觉实施与验收

2026-11-05。基线为[确认的整套视觉稿](<../reviews/2026-11-05-ui-companion/黄晓西 · 黔山同行视觉评审册.pdf>)，运行入口为[游客演示](http://127.0.0.1:8765/design/demo/index.html)。[逐屏对照](../output/companion-visual-review/index.html)可以切换画面和尺寸，右侧链接可打开完整投屏截图。

## 改动落点

| 游玩环节 | 画面处理 |
| --- | --- |
| 相遇、伙伴与导览 | 演示身份使用邮驿场景，选初始搭配时进入工坊。伙伴站在已有景区夜景里，道具与对白围绕人物。地图继续按原画坐标定位实际可点的标记。 |
| 到访与收获 | 各点位使用自己的景物窗口。核验收据显示该次的时间、奖励与实际解锁结果。景区见面礼同时展示整套穿着与四件服饰；单次抽取以实际抽到的资产为主角。 |
| 卡池、试穿与图鉴 | 云山在木廊、花溪在溪边展示。首屏展示整套、四件服饰和本池收集进度，下滑查看其他类别及来源。衣架按当前库存展示，试穿草稿和已保存搭配分别呈现。 |
| 手账、照相馆与作品 | 真实足迹按本地日期排入手账，跨日保留各站时间。同一地点的两次经历可分别打开。单页纪念与足迹长图分别绘制；草稿、生成预览与 PNG 使用同一绘图入口。 |
| 演示身份、票夹与订单 | 手账、票券和回执沿用相同材质。待支付、已到账、取消、失败、次数来源和模拟金额按原数据展示。 |

样式及演示专用的页面、手账和作品绘制在 `design/demo/visual/`。八张运行时场景在 `design/demo/assets/scenes/`。共享页面通过演示配置接收视觉模板，导航、核验、发奖、抽取、穿戴保存、订单和作品保存仍走原有处理函数。领域规则、配置、存档适配与服装穿戴层均沿用基线版本。

## 对照口径与差异

- 48 张整屏稿中，44 张有现成的游客演示画面或对应状态；分别采集 390×844、360×640、1280×720，共 132 张实际截图。对照脚本在独立浏览器内，用可重建的日期和物品组成设计样例；功能彩排从新身份实际操作，使用真实抽取结果。
- 第 02、03、04、41 稿是正式登录、验证码、绑定、账号安全的后续设计。当前演示继续使用本机身份。第 08 稿保留原景区详情的返回路径，第 30 稿的选经历操作沿用制作页内多选框，第 42、48 稿仍在票夹内连续阅读流水与订单。实际金额、经历数量、锁定原因、来源和续行动作均随账号变化。
- 390×844 下，按可见人物边界而非透明图片的外框测量。伙伴首页的设计／实机头顶与脚底均为 **147 / 636 px**；云山卡池为 **103 / 504 px** 对 **104 / 504 px**；衣橱为 **126 / 537 px** 对 **128 / 531 px**。窄屏和矮屏以人物全身、操作可达为准，随屏高调整舞台。
- 逐屏复核后修正了打卡景物裁切、获得单件的尺寸、手账日期和地点图的层次、试衣落脚线，以及保存预览和编辑区的阅读顺序。纪念图保留当前实际选中的经历；长图的纸纹采用独立采样，人物、地点照片和文字按成品尺寸绘制。
- 验收为桌面 Chrome、手机视口模拟与本机可下载图片。手机系统分享面板和现场投影仪色彩需要对应设备确认。

## 行为与作品回归

- 原 14 项领域测试通过。[浏览器边界检查](../output/demo-rehearsal/edge-checks.json)覆盖阶段守卫、重复领奖、跨池排重、收齐、试穿取消返回、订单与异常恢复。
- [四段实际彩排](../output/demo-rehearsal/rehearsals.json)覆盖新身份、刷新回访、复位后再演示及桌面全链路。关联入口保留、实际导出 PNG 均经过操作。[本轮可播放的备用录屏](../output/demo-rehearsal/连续操作彩排.webm)。
- [布局与导出核对](../output/visual-repair/layout-check.json)覆盖五种屏幕尺寸、全部地图点位和部件显示。单页和长图的草稿、预览、存入作品的图片及下载文件逐字节一致。[查看导出样例](../output/demo-rehearsal/旅行纪念.png)。
- [备份／恢复、分享回退及旧作品检查](../output/demo-rehearsal/restore.json)通过；另以改版前视觉修复阶段的测试备份载入隔离浏览器，核对完整存档及其中两张已保存作品，与原内容一致。
