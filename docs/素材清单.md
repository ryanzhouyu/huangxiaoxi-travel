# 运行素材与来源

本包只保留当前画面和合成使用的图片，未重新生成、压缩或修改像素。来源提交为 e5fb44a；逐文件来源、字节数和 SHA-256 见[运行素材清单](../design/demo/assets/manifest.json)，全部原文件去留见[file-inventory.csv](file-inventory.csv)。

- assets/wardrobe：A1、A2、C3 初始款，A4 见面礼，B5 云山、A6 花溪；24 单品缩图、6 套透明图集、头像。frames.mjs 保存拆件定位，不能删。
- assets/scenes：当前场景、衣橱、抽取、手账和纪念图背景；不是过程设计稿。

- icons / painted-icons / symbols：从历史模块提取仍在使用的图标绘制函数，移除旧人物与场景渲染。
- visual/blossom.svg：界面装饰，仍被 CSS 使用。

原始确认稿及拆件母版只在[源分支素材记录](https://github.com/ryanzhouyu/huangxiaoxi-travel/tree/e5fb44a52c8b63fb6d0b3566e2f4094e08d134d7/reviews/2026-11-05-wardrobe/selected)保留；GitHub 私有链接需权限，不影响本包运行。需要重新制作素材时再由项目负责人提供母版。
