# 黄晓西测试与发布验收

更新日期：2026-11-08。状态：持续验收规范，原型回归矩阵继续保留。当前演示复验入口及输出风险见[运行说明](../design/README.md#检查及输出)，服务与动画需按[阶段草案](开发实施任务与里程碑.md)另立验收。v0.3.1 历史执行结果见[两轮自测报告](两轮自测与优化报告.md)，本规范不代表后续版本的检查已经执行。

## 检查按改动选择

| 改动 | 最低检查 |
| --- | --- |
| 仅文档 | 本地引用、状态／版本、规则一致性、目录可定位及差异检查；不重跑全部应用测试 |
| 规则、配置或存储 | 语法、相关业务测试、输入边界、重复操作、旧存档与写失败恢复 |
| 页面与导航 | 关联业务测试、实际浏览器操作、返回／草稿／刷新、手机和桌面布局 |
| 角色渲染与合成 | 三处搭配一致、兼容限制、失败恢复、PNG 实际打开、旧作品固定 |
| 模块化整合或服务接入 | 完整主线、异常、布局与优化回归；服务另测账号隔离、幂等与并发 |

完整体验改动分两轮：先找功能错误与状态损坏，再找冗余跳转、错误引导和反馈缺失。视觉另与整套确认稿逐页对照，实际滚到最底部检查背景连续、导航、固定操作区、安全区及异常空白；投屏检查真实 iframe 尺寸。人物检查头颈连接、透明白边、等比缩放和跨套遮挡。测试断言数不能代替独立场景数，也不能证明审美达标。

## 执行与证据

从工作区根目录执行 `npm --prefix design run check` 和 `npm --prefix design test`。浏览器先启动服务及 Playwright CLI 页面，再运行所需脚本；具体命令见[运行说明](../design/README.md)。测试使用独立浏览器上下文，不重置用户当前体验账号。

| 脚本 | 当前结果位置或变量 |
| --- | --- |
| `browser-flow.js` | `window.hxxQA`；`design/verification.json` |
| `game-visual.js` | `window.hxxGameQA`；`design/game-verification.json` |
| `audit-round1.js` | `window.hxxAudit1`；`design/audit-round1-after.json` |
| `audit-round2.js` | `window.hxxAudit2`；`design/audit-round2-after.json` |
| `audit-recovery.js` | `window.hxxRecoveryQA`；`design/audit-recovery.json` |

当前 JSON 属于 v0.3.1 历史记录，新版本应重新执行并记录日期／版本；不要只改文件标题。新 bug 先记录复现路径，修后按原路径复测；错误、取消与存储失败都验证业务数据未被误改。

布局参考尺寸为 360×640、390×844、430×932、1440×1000。直接查看首页、地图、衣橱、卡池、获得、回忆及入口截图；实际点击关键操作，检查溢出、遮挡、层级和文字。真实手机另测系统扫码入口、下载与原生分享；不支持分享时有下载替代，用户取消不记作已发布。

文档检查执行 `python docs/check_docs.py`，默认写入忽略目录 `.codex/local-deploy/docs-check.json`；用 `--report` 指定本次正式证据位置。业务含义仍需人工核对；[本轮整理验收](项目复盘与资料整理记录.md)与[2026-10-19 历史验收](文档整理与验收记录.md)分开。

## 发布前清单

- [ ] 本次范围、实际版本、已完成／模拟／未接入清单与文档一致。
- [ ] 对应检查已在本次改动后执行，结果无未解释失败；PNG 已实际打开。
- [ ] 无账号、初始化、领取、抽取、搭配与作品主线回归，必要的两轮检查已完成。
- [ ] 用户进度未被测试污染；旧结构兼容，新结构迁移已演练恢复。
- [ ] 目标环境可访问，部署目录／资源路径正确；二维码使用目标地址，不使用手机无法访问的电脑 localhost。
- [ ] 手机相机／原生分享的实际验证与局限写清；生产服务接入时，身份与权威结算已有证据。
- [ ] 文件／版本可恢复；涉及数据迁移时同时备有数据恢复步骤，不能只回退静态文件。

以上是每次发布要执行的模板，当前不预勾选。原型可静态部署；公开部署不等于具备真实身份和生产业务能力。
