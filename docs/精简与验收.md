## 验收口径

独立工作树、端口和浏览器上下文，不动原项目用户存档。核对语法和导入、动态素材、文档及禁止项；免费业务与旧数据保护；新账号到实际 PNG；草稿保存／取消、错码与重复、缺次与锁池；手机／桌面布局和资源／控制台错误。

## 已执行结果

机器可读结果见 [acceptance.json](acceptance.json)。环境：Windows、Node 24.12.0、Python 3.14.2、Chromium 157.0.8103.51，独立端口 8767。

- 静态检查：23 个 JS 模块语法、21 个运行模块入口可达、全部 42 张图片哈希与动态服装映射、文档引用和交付排除项通过。
- 领域测试：15 项通过，覆盖免费资格、排重、锁池、收齐不扣次、旧图不变、存储失败与旧 orders 兼容。移除旧支付用例，以免费到访／活动获取测试次数。
- 第一轮：新身份 → 初始化 → 免费领装 → 错码／成功核验 → 商家与活动 → 9 次抽取 → 保存搭配 → 回忆合成／保存／下载。导出 680×930 PNG 并实际打开检查；刷新和换装不改旧图。
- 5 种窗口（360×640、390×844、430×932、1440×1000、1280×720）× 9 页共 45 组，未发现缺图、横向溢出及导航越界。页面错误和失败资源响应均为 0。旧控制台、高保真与原型路径均返回 404。
- 第二轮：刷新保留草稿、模拟存储失败不假保存及重试、无效链接／无经历生成保护、跨标签切号、损坏存档不清空通过。
- 此轮发现并修复：另一标签页完成初始化后，原页面可能滞留初始化页。所有存储同步均重新执行路由守卫；复测跨标签新账号初始化通过。
- 入口、伙伴、地图和衣橱与原版同搭配截图比较：地图像素完全一致；其余仅微小像素差异，单通道差值超过 20 的像素均为 0。已直接看截图确认人物、布局和素材保留；这不是全部页面的逐像素一致承诺。

## 限制及复现

浏览器验收的截图、PNG 和执行脚本在本机忽略目录 .codex/review/、.codex/browser-review.js 与 .codex/browser-recovery.js；本包只保存结果，不重新携带一批过程截图。跨标签回归可手动复现：两个标签打开同一新手账，在其中一页初始化，另一页应进入伙伴；有草稿时切换身份，应展示新身份且不写回旧草稿。

没有真实账号、后端、连续动画或手机真机验收。默认 Node 22+ 的运行说明仅为环境下限建议，本轮实际测试 Node 24.12.0。压缩包在最终提交后另按 Git 树核对全部文件及 ZIP CRC；此报告不冒充生产发布验收。
