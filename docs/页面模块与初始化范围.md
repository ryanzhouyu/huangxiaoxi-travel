# 黄晓西页面与模块目录

更新日期：2026-10-19。文档版本 v0.2，核对应用 v0.3.1。本文是当前页面／模块清单，交互细节以[完整体验与验收标准](完整体验与验收标准.md)为准。早期 13 类页面及初始化安排已移至[历史结构方案](history/2026-10-19-structure-v0.1/页面模块与初始化范围.md)，不再用于安排当前开发。

## 16 类当前页面

以下是共享原型／演示的业务路由基线。当前演示的新增呈现与三栏辅助模块见[运行索引](../design/README.md)，独立高保真 21 页及账号设计不等于已接入服务。下一阶段真实账号的页流在方案确定后更新此处。

编号按职责统计，不表示 16 种独立布局。路由为当前 hash，不把最初拟议的 URL 路径当成已实现接口。主导航只有 `partner/explore/memories` 三个根页面。

| 编号 | 页面及当前路由 | 职责和主要动作 | 模块 |
| --- | --- | --- | --- |
| P01 | 账号入口 `#entry` | 选择演示账号；恢复或首次进入 | M01 |
| P02 | 初始伙伴 `#onboarding` | 三套初始预览，确认默认搭配；全部初始装扮免费 | M01、M05 |
| P03 | 伙伴 `#partner` | 场景人物、回应、背包／图鉴／打卡、账号及次数入口 | M05、M07 |
| P04 | 游玩 `#explore` | 景区选择和已有足迹提示；当前一个测试景区 | M02 |
| P05 | 景区导览 `#scene` | 示意地图、分类、地点一览、免费套装与卡池 | M02 |
| P06 | 地点详情 `#point?id=…` | 查看奖励、扫码／定位模拟、关联卡池；商家额外有活动入口 | M02、M03 |
| P07 | 打卡核验 `#checkin?id=…&code=…` | 确认点位、输入或解析测试码、验证并记录；参数按入口可选 | M03 |
| P08 | 活动 `#activity` | 固定手作活动条件、独立奖励、店员核验模拟 | M03 |
| P09 | 卡池 `#pool?id=…` | 套装展示、奖励与概率、锁定／可抽／收齐、单抽及模拟购买 | M04 |
| P10 | 衣橱 `#wardrobe?from=…` | 人物与部件同屏；分类、试穿、保存／取消并返回来源 | M05 |
| P11 | 套装图鉴 `#collection` 或 `#collection?id=…` | 套装收藏、部件进度与来源；未带 ID 查看收藏目录 | M05 |
| P12 | 回忆 `#memories` | 足迹／作品页签、日期范围、经历详情、开始制作 | M06 |
| P13 | 纪念图制作 `#compose` | 经历、标题、模板、调整搭配、生成预览与保存 | M06、M05 |
| P14 | 作品详情 `#work?id=…` | 固定图片、经历快照、下载／分享、用当前搭配再制作 | M06 |
| P15 | 账号 `#account` | 进度说明、切换身份、次数入口；验收工具折叠隔离 | M01 |
| P16 | 次数与订单 `#wallet` | 收支记录、订单状态、继续待付模拟订单 | M04 |

`from` 需编码完整来源路由与参数，不只写页面名。`scene/activity` 当前单实例固定，未来多景区／活动需要显式参数与契约迁移；本表不代表已经实现多景区服务。

## 弹层及公共状态

| 编号 | 弹层 | 操作与结果 |
| --- | --- | --- |
| O01 | 免费套装获得 | 已入库；立即试穿或先收好，领取不自动穿戴 |
| O02 | 打卡／活动结果 | 经历、实际奖励、解锁；继续玩、看池或用此经历制作 |
| O03 | 获得装扮 | 入库结果；试穿、继续单抽／找次数、收好；收齐有去向 |
| O04 | 套餐选择与模拟支付 | 创建待付订单；成功／失败／取消，关闭可保留待付状态 |
| O05 | 草稿离开确认 | 保存并继续、放弃并继续、继续编辑；保留目标路由 |
| O06 | 反馈与来源详情 | 错误、空态提示、部件来源、经历详情、地图地点一览等公共内容 |

六项是职责组，包含多个实际弹层，不表示 UI 只有六种状态。每类页面还需具备相应无数据、读取失败、加载／忙碌、无效 ID 和完成状态，详见交互规格。

## 模块与跨页依赖

| 模块 | 数据与能力 | 关键页面 |
| --- | --- | --- |
| M01 入口与会话 | 演示身份、初始化守卫、恢复目标 | P01、P02、P15 |
| M02 景区与点位目录 | 景区、点位、活动、卡池配置关系 | P04—P06 |
| M03 到访与领奖 | 核验、事件、资格、发次与解锁协调 | P06—P08 |
| M04 卡池与次数 | 候选、扣次入库、流水、模拟订单 | P09、P16 |
| M05 衣橱与收集 | 拥有、保存搭配、试穿、收藏进度 | P02、P03、P10、P11 |
| M06 回忆与作品 | 经历筛选、制作、图片与作品快照 | P12—P14 |
| M07 公共界面与配置 | 导航、反馈、设计变量和配置装配 | 跨页面复用，不单独成为首页功能列表 |

关键闭环：P01→P02→P03；直接扫码经必要前置回 P07；P05 领取→P10 保存回 P05；P07／P08→O02→P09；P09→O03→P10；P13→P10→P11→P10 保存回 P13；P16 继续订单→O04→原 P09；P12→P13→P14。

领取套装、抽取或换装不都是每次制作的前置步骤；有有效到访即可制作。不能因模块依赖把游客强制带回完整新手流程。
