# 黄晓西换装体验子环节确认清单

更新日期：2026-10-19。状态：13 张卡片已答复的确认记录。当前规则见[产品规则](一期产品规则与业务流程.md)，具体页面见[交互规格](完整体验与验收标准.md)。以下提问范围保留作确认依据，不是当前待答清单。

确认目标是让功能可实现、规则可计算、结果可验收。每个子环节需要形成游客操作、系统处理、后台维护、保存内容和验收例子；不把数据库、框架或按钮排版选择转交给用户。

## 一 需要确认的问题范围

| 环节 | 需要业务判断的内容 | 确认后形成的开发依据 |
| --- | --- | --- |
| 入口与伙伴 | 运行载体与账号、初始装扮归属、已有角色资源 | 首次建立与回访流程、资产初始状态、素材实现范围。 |
| 景区免费体验 | 免费套装可用范围、领取与穿戴关系、现场扫码首次进入的衔接 | 领取规则、直接入口处理、套装发放与穿戴状态。 |
| 实地打卡 | 本周真实或模拟的核验方式、领奖周期、商家到店与消费／体验条件 | 点位与活动核验规则、奖励配置、打卡和发奖记录。 |
| 抽取与购买 | 是否重复、概率模型、奖池抽空、模拟购买的套餐与余额使用 | 可抽奖品集合、扣次发奖规则、订单与次数账本、运营配置。 |
| 装扮与表现 | 首期可换部位、表情与动作的实际表现、素材适配范围 | 可替换资产清单、穿戴规则、伙伴与出图一致的合成方案。 |
| 回忆与分享 | 回忆的经历范围、历史与当前形象选择、图片产出方式 | 记录内容、图稿模板、生成与保存流程、跨日作品样例。 |
| 运营与验收 | 本周需要哪些可操作管理能力、示例数据范围 | 管理端最小功能、初始配置、测试账号与端到端验收清单。 |

以上按实现依赖推进，不要求全部问题一次答完。核验、奖励和素材能力优先，因为它们会改变接口与工作量；领取交互和页面布局先给可逆的默认方案。

## 二 已确认的卡片结果

| 卡片 | 确认结果 | 对实现的影响 |
| --- | --- | --- |
| 01 载体与账号 | 独立手机网页，演示账号验证进度保存，暂不接现有系统。 | 先完成独立部署；进度归属演示账号，不依赖现有产品登录接口。 |
| 02 初始装扮 | 所有初始装扮免费可用，首次选择只决定默认搭配。 | 初始资产统一发放；选择模板改变当前搭配，不改变其他初始资产的拥有状态。 |
| 03 角色资源 | 当前主要为画板图片，先用简化的可替换素材跑通。 | 首期必须验证部件替换与纪念图一致，不将整张原型图当作换装引擎。 |
| 04 核验能力 | 二维码打卡实际可用；定位与活动核验先模拟。 | 支持生成、扫描并识别测试点位二维码，保存打卡与发奖结果；模拟核验明确标识。 |
| 05 普通点位领奖 | 同一游客在同一普通入口／景点只在首次有效到访时获得次数。 | 首次领奖资格独立保存；后续到访记录与是否发奖分开判断。 |
| 06 商家与活动 | 到店扫码可获到店奖励；消费或体验完成另需店员核验。 | 区分到店与完成活动条件；本周活动核验按卡片 04 模拟，不默认扫码就代表完成消费。 |
| 07 跨池排重 | 已拥有的奖励不再抽到，跨卡池也排除。 | 按账号持有的统一资产标识筛选，不按每个卡池分别判断是否拥有。 |
| 08 概率 | 当前可抽的未拥有奖励等概率。 | 先排除已拥有项，再在剩余奖励中均匀抽取。 |
| 09 动作与表情 | 可切换的静态姿势与表情，首页与纪念图均可使用。 | 采用一致的静态合成资产，一期不接动画或实时角色引擎。 |
| 10 出图方式 | 固定模板合成伙伴、景点背景、时间与路线信息。 | 一期不接 AI 整图生成，使用可复现的纪念图合成流程。 |
| 11 出图搭配 | 使用当前保存搭配，可换装后重新生成，旧作品不变。 | 生成时固定所用搭配与素材版本，保存独立输出文件。 |
| 12 运营范围 | 固定测试配置，仅验证游客端，后台页面后续再做。 | 集中配置景区、点位、活动、奖励、卡池和套餐，保留业务所需服务端处理。 |
| 13 商家活动周期 | 每个商家到店奖励、每项活动奖励，均为每个账号一次。 | 到店和活动分别保留唯一领奖记录。 |

二维码实际可用指手机扫码能够打开对应点位、完成测试核验并触发记录与发奖，不等于已接入真实景区，也不等于静态二维码已经能证明不可转发的现场到访。

## 四 可先采用的实现方案

下列方案已在当前原型采用，但不因此升级为用户确认的正式业务规则；变更时仍需检查是否影响已确认范围。

1. 每个演示账号拥有一个持续保存的伙伴，刷新和回访恢复已有状态；不同账号的资产、余额、打卡与回忆隔离。
2. 每景区默认套装领取后进入资产库，领取与当前穿戴分别保存；重复点击不重复发放。
3. 现场扫码首次进入时，若没有伙伴先完成必要建立，然后回到原点位继续；不强制先走线上浏览或领装。
4. 中奖资产自动入账，试穿只改变预览，保存后统一更新首页与后续作品使用的伙伴形象。
5. 打卡重试、订单回调、抽取重试保证不重复发奖；这些技术一致性要求直接落实，不额外占用业务讨论卡片。
6. 留存真实事件与来源，不以购买、线上浏览或换装伪造到访；模拟数据按测试范围进入演示回忆。
