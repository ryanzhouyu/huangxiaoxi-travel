# 黔山同行前端体验优化与评审

2026-11-18 · 基线 `43b0ba8` · `codex/production-frontend`

原型面向独立移动网页，使用已确认的黄晓西身份、六套服装及黔山同行场景体系。评审交付包含实际试穿、核验结果、抽取、草稿、制作和导出。从[评审工具](../design/review/desk.html)进入，[视觉对照](../output/frontend-review/2026-11-18/index.html)可逐页查看。业务边界以[产品规则](一期产品规则与业务流程.md)为准。

## 回顾与优先级

本轮重新从独立身份复演 11 月基线，完成首次进入、线上领装、地点与活动、抽取、搭配、生成 PNG、下载及手账恢复。基线的 44 张状态截图重新采集，实际业务闭环另用连续操作验证。原演示已验证场景与六套资产能够贯通，正式登录、现场核验、云进度和连续角色动画仍待接入。

| 优先级 | 本轮观察 | 处理方式 |
| --- | --- | --- |
| 保留视觉基础 | 夜景人物、连续地图、纸册和照片已经建立产品气质。历史修复过地图接缝、导航对齐和人物落脚 | 延续场景母版与服装 ID，每屏用共同的纸面、控件和字号重新组织 |
| 收口主线 | 演示从选择本机身份进入，现场和店员使用模拟成功，卡池和钱包包含模拟购买 | 增加可操作登录和深链恢复，评审凭证独立提供，游客页遵守免费首发范围 |
| 改善效率 | 衣橱部件挤在窄衣架，分类在下方。卡池状态和动作分散在长页 | 人物下方摆放类别和选件。统一拥有、试穿、已穿标记，固定当前主要动作 |
| 改善阅读 | 手账日期、筛选、照片和状态争抢重点，制作选项与结果距离较远 | 日期组织照片段落，照相馆先展示实际草稿，再放模板、搭配和经历 |
| 准备真实接入 | 景区目录和核验方法为评审配置，既有实机证据来自桌面 Chrome | 按真实页面动作交接，随后依次落实接口、现场素材、真机与微信验收 |

| 预览与作品 | 图片独立于控件，收藏和保存到设备分别呈现 | 放大、回编辑、收藏、下载、分享及再制作。编辑后旧预览失效，实际 PNG 与收藏图一致，分享取消可恢复 |
| 身份与次数 | 纸面身份与退出，景区票签与可追溯收支 | 退出需确认，可重进恢复。流水查看来源、时间和余额。账户变更隔离草稿与作品 |
| 公共状态 | 同一组返回、纸面、焦点、选中、表单错误、弹层和提示 | 主导航只在伙伴、游玩、回忆根页。无效链接、有损存储和素材读取给出可理解后续。弹层关闭后尽量回发起操作 |

## 视觉与素材验收

- 390×844 为主要设计视口。暖纸、深棕、莓红主操作和苔绿选中贯穿模块。正文 16px，次级 14px，短辅助标签可更小。主要控件触区以 44px 为目标。
- 夜景、山水图、邮驿、工坊、云山廊、花溪、礼台、手账纸与照相馆沿用确认素材。场景负责气氛，位置、状态、文字和奖励由实际数据呈现。
- 伙伴、衣橱和纪念图复用同一角色渲染。原部件 ID 和确认的六套服装保持对应。正式场景照片、地图坐标与授权继续由运营和前端核实。
- 矮屏、长屏和桌面检查人物完整、类别可达、底部安全区、长页末尾及固定操作区。作品检查真实导出文件、保存搭配和来源快照。
- 界面反馈与角色连续动作分别验收。后续按[动画样板](动画样板制作与技术评估.md)验证连续关键帧及跨套兼容。

## 实施验收记录

- 基线复验完成 4 条连续彩排及 44 张 390×844 状态截图。基线保留当时的模拟订单路径。
- 新原型通过 23 项浏览器验收记录，采集 87 张新版截图，画廊覆盖 54 个画面与状态。覆盖 360×640、390×844、430×932、1440×1000、1280×720，额外检查 30px 底部安全区与手账、制作页底部。
- 新身份实际完成领装、到访／独立活动、抽取、试穿、跨日经历选择、保存和下载。响应丢失可刷新后查询一次原结果，重复到访首奖不再发，收齐不扣次。浏览器返回与跨标签保存均复验草稿保护。
- 打开实际导出的 [680×950 PNG](../output/frontend-review/2026-11-18/travel-keepsake.png) 检查人物、地点、日期和构图。下载文件、预览和入库图片逐字节相同，后续换装和刷新未改写旧作品。
- 验收环境是 Windows 桌面 Chrome。手机尺寸使用模拟视口，跨日使用测试时钟，分享回退使用浏览器能力替身。iPhone／Android 实机的软键盘、现场相机、微信内保存与系统分享仍待实测。
