# 景区导览主线接入与验收

2026-11-19 · [进入游客端游玩](http://127.0.0.1:8782/design/review/index.html#explore) · [黄果树章内确认稿](../output/huangguoshu-chapter-guide/2026-11-19/README.md)

## 接入范围

访客在「游玩 → 打开游玩地图」进入章内导览。确认稿的青绿山水、地标道具、卡池弹层、票券和服饰横幅进入 `design/review/`。沿用游客端的共用导航。初见礼和地点一览放在地图顶部，按景点、商家和活动筛选地点列表，地图保持全部点位可见。

本机评审沿用「黔山漫游」目录和 `hxx.review.v1` 进度。山门入口、望山台、花溪小径、山间手作铺分别对应上方滩瀑、主瀑、下方溪畔和店铺锚点。示意图不承担现场导航。全景区有两套池内服饰，底部以现有账户已集齐的套装和跨池去重后的奖励项目计算概览。

## 游客路径

| 操作 | 结果 |
| --- | --- |
| 点地标或地名 | 居中打开该点实际关联的卡池，显示打卡、解锁与奖励收集状态。关闭、按 Esc 或浏览器返回回到原点。详情地址刷新后可恢复。 |
| 点记录到访或记录到店 | 进入原核验页。有效凭证提交后更新足迹和资格。回执可返回地图或进入新解锁的池。 |
| 从点位详情进卡池 | 进入原抽取页，抽取按既有资格与库存结算。返回相同景点可查看最新收集状态。 |
| 展开全部奖励 | 查看本景区卡池、套装和解锁地点，点池名可继续查看。单独访问旧点位地址仍可打开原详情。 |

## 复验

在本机 Chrome 的独立上下文，走新身份、领取、无效凭证、到访与共享池、抽取与丢失响应恢复、换装、手账和实际导出。另用同一测试存档在 360×640、390×844、430×932 模拟触屏，逐个点开四处地标，在 1280×720 与 1440×1000 核对桌面弹层位置，并检查 30px 模拟底部安全区和 360×400 弹层滚动。业务继续由[现有评审服务](../design/review/README.md)处理。正式目录、现场扫码与后端服务待接入。

本轮通过 31 项主线浏览器验收、6 组导航视口、14 项领域测试和文档链接检查。独立确认稿换用共用素材路径后，实际打开了大瀑布居中弹层，资源加载通过。
