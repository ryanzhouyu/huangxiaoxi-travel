## 自验结果

1. 15 个契约场景通过：深链不丢目标，非法返回地址拒绝，登录换账号不重放旧写入，客户端不能提交权威余额／奖品，输入顺序不误判重试，搭配专用版本，作品非空来源；以及迟到资源、重复完成通知、连续点击、眨眼优先级、后台恢复和卸载保护。
2. 另有 8 个迁移预检场景通过：明确所选手账、源数据不变、余额／流水一致性、未知资产与资格、重复奖励、作品引用／快照、摘要稳定及坏输入拒绝。全部为合成数据，预检始终返回不能直接导入。
3. 自审修正两类候选边界问题并纳入回归：重复加载通知或返回同一缓存句柄时不能释放当前展示资源；requestId 和命令名称必须拒绝数组等隐式字符串转换。迁移预检另补了未初始化手账出现业务数据的拒绝提示。修复后重跑通过。
4. 数据库实验因 Docker Engine 管道请求返回 500 而在容器检查阶段停止。尝试启动本机已安装 Docker Desktop 后仍不可用；未重置 Docker、WSL 或用户环境，未安装另一套数据库。此项记为环境不可用，不能据 SQL 文本宣称事务已验证。
5. 文档引用、任务计数、原规则与演示保护检查另存本次报告。游客代码、素材、业务 ID 和历史证据不变；本轮没有 Web UI 改动，不重复全页截图或宣称真机通过。
