# 手机号登录与短信接入准备

2026-11-08。用户先选择“优先手机号验证码、准备短信主体材料”，随后明确**主体未定，登录可以先不接真实手机号和短信验证**。因此保留手机号方向、暂缓真实接入；没有申请云账号、短信、域名，没有发送或采购。D01 的渠道方向明确，接入条件尚未齐备。

## 当前可继续的工作

登录、初始化和恢复状态按[账号流程](账号流程与接入决策.md)细化；认证、业务写入及渲染分层，未来实际短信由服务端适配。当前演示 A/B 仍是本机手账，不因为手机号输入框或固定验证码而升级为真实账号。

后续若为开发联调加入测试会话，只能在独立开发／测试入口，由服务端明确启用并限制受邀测试身份；显示“开发验证，未接短信”，不得提供任意手机号认领账号的能力。测试身份使用独立命名空间，接正式认证时通过可信绑定确认，不按手机号文本自动合并。真实身份、跨设备生产权限的验收仍暂缓；修改阶段放行口径需清楚区分开发联调与正式内测。

## 恢复接入时需要准备什么

| 顺序 | 负责人／交付 | 验收条件 |
| --- | --- | --- |
| 1 主体与管理员 | 用户指定实际企业／机构及可协调管理员；确定账号归属 | 不是项目显示名或临时测试签名；主体待定时不申请 |
| 2 云服务方案 | Codex 提供候选、区域／访问条件、费用和退出迁移方式；用户确认具体开通项 | 当前只查条件，不默认供应商或可免费长期使用 |
| 3 实名及授权材料 | 管理员按所选服务商控制台要求提交；自用／他用关系明确 | 正式资质通过；证件原件、私人手机号、密钥不进入聊天或 Git |
| 4 签名与验证码模板 | 提交合法签名及单一登录用途模板 | 平台审核、运营商生效条件及模板均满足；不能只看一项“审核通过” |
| 5 服务侧接入 | 最小权限凭证、服务端适配、限流、费用上限／告警及脱敏日志 | 浏览器无密钥、不可回传验证码、不可任意发送模板或改签名 |
| 6 实际联调 | 受邀同意的测试号码与四手机环境；验证码、重试、失效、退出、换账号 | 真正收到并验证、不会多次消费、可恢复原页面；失败不能显示发送／登录成功 |

腾讯云官方当前区分企业自用和他用资质；公司／机构签名与商标有不同证明条件，个人自用签名受限，他用需适当授权。详细要求以[签名审核标准](https://cloud.tencent.com/document/product/382/39022)及实际控制台为准，不将早期国际站／旧 PDF 中的宽松条件套到当前国内接入。

阿里云国内短信也要求相应企业资质和审核材料，个人认证账户不能凭任意项目名免除企业资质要求；见[使用须知](https://help.aliyun.com/zh/sms/user-guide/usage-notes)及[新增资质](https://help.aliyun.com/zh/sms/user-guide/apply-qualification/)。这只是备选条件比较，不代表已经选用任一平台。费用和生效时间需实际报价／审核，不承诺开通日期。

建议模板草案：“您的登录验证码为 {code}，请在 {minutes} 分钟内完成验证。如非本人操作，请忽略。”这不是已审批模板，变量格式、长度及固定期限须按最终平台调整；签名暂不写成“黄晓西”已经可用。验证码不附带营销文案或核验领装动作。

## 实现与异常细节

| 环节 | 实施要求 |
| --- | --- |
| 输入 | 国家／地区支持范围在接入前冻结；手机号不放 URL、埋点或公开日志。使用合适键盘与自动填充提示，不靠输入格式证明身份 |
| 挑战 | 服务生成随机 challengeId；绑定用途、规范化手机号、当前认证流程及到期。发码／校验状态与业务初始化分开 |
| 发送中／未知 | 去重发送请求、服务限流；未知结果先查询，不能自动循环发送产生费用；不把供应商接受请求等同于用户已收到 |
| 验证 | 服务端校验、限尝试、一次消费；成功才创建／查回稳定 accountId 并建立会话。一次挑战不能验证到别的手机或跨用途使用 |
| 重发 | 依据服务时间显示冷却；新挑战与旧挑战失效关系明确，不能让迟到短信覆盖当前页面。具体参数按供应商和安全评估冻结 |
| 切应用／刷新 | 保留非敏感目标及挑战关联，不保存验证码；重新查服务状态后恢复。错误／过期可更正，不丢点位来源 |
| 换账号／失效 | 原账号草稿与未知请求隔离；同账号先查原结果，另一账号不重放。迁移待审批内容也必须核对目标身份 |
| 暂停服务 | 明确当前不能验证，可重试／稍后进入，不给“万能验证码”绕过；测试入口与真实入口分别发布 |

验收归口 AU01—AU08、SY03、UX01。代码契约测试只覆盖前置与返回，不证明短信送达、认证安全、平台审核或四环境真机已通过。
