## 每次设计复用的顺序

1. 指定一个能当场看见的目标。例如衣橱第一眼看到晓西穿着什么，第二眼看到可以换什么，最后能明确保存或返回。
2. 列出每个元素的意思、素材来源、文字和动作。组件共用阅读顺序、轮廓、语义、触区和状态，场景使用各自确认的纹理和收边。
3. 先做 390×844 基准，加 360×640 小屏、长屏、桌面及底部安全区；对照的是同一条数据和场景。图片、形状和文案逐项查。
4. 先跑交互与恢复，再看首屏、边界、长内容和失败。修改后重查影响的状态。样板通过只覆盖当次验证范围，正式实现后再跑真实流程与设备。
