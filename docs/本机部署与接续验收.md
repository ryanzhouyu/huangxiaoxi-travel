在项目根目录的 PowerShell 中执行：

```powershell
.\Start-Local.ps1
```

脚本优先寻找本机 Codex 附带的 Python，再检查 PATH 中的 Python 3，避免本机 Windows 占位入口造成启动失败。当前端口已有相同入口内容的服务时复用；被其他服务占用则报错。手动新启动时保持终端打开，Ctrl+C 停止；可用 `-Port 8766` 指定其他端口。端口变化会使用另一份浏览器存储。

本机实测环境为 Node.js v24.14.0、npm 11.9.0、Python 3.12.14。无需安装应用依赖或执行构建；浏览器检查使用 Playwright CLI。维护脚本的完整依赖仍以根目录 requirements-tools.txt 为准。
