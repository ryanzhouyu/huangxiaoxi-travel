## 当前问题与候选设计

| 问题 | 当前样板观察 | 候选稿处理 |
| --- | --- | --- |
| 选衣与底部操作割裂 | 一次试穿要在下方换类别、右上点部件、中间看人物、再回下方确认。右侧还有独立件数、滚动和状态。 | 在手机把类别、当前部件名、横向选衣与保存按从上到下排进同一区域。六件上装可横滑，桌面滚轮也能翻。保存、恢复和取消在同一基线，各有独立可点范围。 |
| 字形、材质和边框争抢 | 楷体标题、偏重的操作字、深色衣架内浅卡、描边胶囊和重复工坊木纹同时抢眼。上装缩略图与页头共用了 `.top`，造成缩略图尺寸被页头样式干扰。 | 宋体标题提供工坊气质，操作统一用无衬线中文。实测 Windows Chrome 标题为 SimSun，类别与部件为 Microsoft YaHei。标题 23–29px，类别 13px，部件名 12px，辅助状态 11px。选中项一圈线、类别一根线、保存一块暖棕色，底部用同一浅暖哑光面。 |
| 人物轮廓不清 | 晓西偏左，轮廓恰好压着明暗变化大的织物、窗框和地毯。室内背景和桌面都重复同一画面，质感层次接近。 | 人物居中并保持清晰，背景降低明度和饱和度，远处轻虚化，靠近鞋底的地面逐步恢复细节，加一层很浅的接触影。保留窗、织物与地毯，预览背景时使用对应取景。 |

优先评审下方选衣版。390×844 的人物可见高度从上一轮约 421px 增到约 490px。360×640 下方操作需要多占一段高度，人物由约 322px 减至约 304px，居中后挥手、脚尖和裙摆仍完整。对 7 个部位的短、长列表预留同一行高，避免换类时画面跳动。若以后确有宽屏大量选品需求，分类与选品同列的侧栏仍是备选。

## 复验与使用边界

- Windows Chrome 157 检查 360×640、390×844、430×932、1280×720 和 1440×1000，记录人物不透明轮廓、场景与操作区交界、文字溢出和至少 44×44px 主要触区。检查中修正了板块因滚动条变化而跳动及上装状态被挤出边框的问题。
- 360×640 实测六件上装的末项、模拟触摸横滑与桌面滚轮，覆盖各部位、图鉴返回位置、恢复草稿及取消。模拟底部 30px 安全区并注入保存失败时，保留试穿和重试入口，重试返回同一个照相馆样本上下文。
- 使用既有素材、独立评审进度及实际浏览器渲染。当前交付为可操作候选稿，视觉取舍待评审。手机、微信真机、正式游客入口和连续动画属于后续接入验收。

## 底部放大与单品查看

用户认可下方选衣版的整体画面，希望操作区更舒展，衣服和背景更容易看清。本轮保留已认可的工坊、人物构图和字体，在独立候选中增加大小两种查看方式。

| 操作 | 设计与验收 |
| --- | --- |
| 快速试穿 | 横滑单品轨道，点图片立即预览。服装预览框从 43px 高增到 72px。窄屏优先显示三件完整单品和下一件边沿；选中、已保存状态在单品下方。背景缩略图取场景中段，表情和姿势保留对应图形。 |
| 看清细节 | 点「查看大图」浏览当前类别的已拥有项。当前试穿在可见范围时先显示它，其余情况从第一个完整可见项开始。服饰用现有透明单品图，背景大图显示原画全幅。可用上一件、下一件或键盘左右键浏览。 |
| 返回与提交 | 看图不改变搭配；关闭后恢复横滑位置和焦点。点「试穿这一件」或「预览这个背景」回到舞台并定位该项，仍须显式保存。底部移去重复部件名称行和取消入口，左上返回继续处理放弃、保存或继续试穿。 |

按上一轮相同样本在五档浏览器视口通过八组检查。360×640 和 390×844 的底部约少占 9px 高度。另验证了 360×640 下的大图浏览、关闭后滚动及焦点、选中不同单品后的焦点、原画不裁切，以及模拟 30px 底部安全区的操作。候选在独立样板中运行，手机和微信真机仍属于后续接入验收。
